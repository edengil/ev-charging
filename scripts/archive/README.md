# scripts/archive

סקריפטים חד־פעמיים / שאריות פיתוח — הועברו לכאן בריפקטור 2026-09-30.
לא מורצים ע״י `npm run` ולא ע״י ה־workflow. נשמרו למקרה שצריך להציץ בהיסטוריה.

- patch-car-logos-code.mjs — תיקון חד־פעמי ללוגואי רכבים (השתמש ב־car-brands-snippet.js)
- patch-complete-session.js — תיקון חד־פעמי למסך סיום טעינה (השתמש ב־_complete_session_new.js)
- patch-import-data.js — תיקון חד־פעמי לייבוא נתונים
- car-brands-snippet.js, wevo-history-view.snippet.js — סניפטים
- _archive_view_only.js, _complete_session_new.js, _balance_out.txt, _chunk_out.txt — שאריות
